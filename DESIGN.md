# Kinex playground visual system

Inherits BluPe's charcoal camera stage, uncropped images, Arial operational typography, soft blue Run and deep red Stop. Desktop uses a 3:1 camera/task split; mobile stacks the cameras above the complete task form. Native focus, disabled controls, persistent status, real errors and public-history empty state remain visible. This is a new integration page, not a redesign of the shared playground. No generated camera imagery or promotional claims.
